## 二、系统现状（当前版）

**架构**：
- 后端：Flask（`career-system-back/backend`），端口 5000，直连 SQL Server
- 前端：Next.js + Ant Design（`career-system-front`），端口 3000
- 数据库：SQL Server `career_system_prod`，34 表

**已跑通的完整闭环**（API 级 62 项断言 + 浏览器 UI 实操双重验证）：

```
注册（自动建 students 档案）→ 登录（JWT，返回真实 student_id）
  → 完善画像（专业/年级/GPA/意向城市）
  → 霍兰德测评 30 题（落库，兴趣类型百分比）
  → 技能测评 10 题（13 专业下拉，映射词库落库 student_skills）
  → 价值观测评 24 题（落库）
  → 岗位推荐（四维加权：霍兰德 0.35 / 技能 0.30 / 学业 0.20 / 偏好 0.15，
     理由含分项分数）
  → 课程推荐（技能缺口驱动，从 4805 门真实课程中推荐）
  → 职业路径推荐（12 条数据驱动路径）
```

**核心数据规模**：

|---|---|
| 岗位 | 2102（国聘采集，覆盖 92.9% JD、100% 行业、99.6% 霍兰德、62.3% 薪资数值） |
